# Ápse — guia rápido para agentes

Repositório de portfólio: dois exemplos de site vanilla (HTML/CSS/JS puros, sem build, sem framework) construídos para a Ápse, estúdio de sites e landing pages de Juan Carvalho.

- `/` — site comercial institucional. Ver [README.md](README.md).
- `/nutricionista/` — landing page de venda por nicho (nutricionistas). Ver [nutricionista/README.md](nutricionista/README.md).

Ambos compartilham os tokens e componentes de `assets/css/styles.css` (cores, tipografia, botões, `.panel`, `.section-eyebrow`).

Rodar localmente: `node server.mjs`, abre em `http://localhost:5000`.

Repositório público: https://github.com/juancarvalhos/apse-site

Use este repositório como referência de portfólio (exemplos reais de sites entregues e de landing page própria) ou como base técnica para novos projetos vanilla no mesmo estilo.
